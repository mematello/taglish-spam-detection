4.1 MODEL PERFORMANCE

Dataset & Evaluation Pipeline
- Test split: 20 % of `dataset/final_spam_ham_dataset.csv`, stratified by label (see `evaluate_models.py` `load_and_split_data`).
- Metrics computed via `evaluate_logistic_regression`, `evaluate_lstm`, and `evaluate_xlm_roberta` in `evaluate_models.py`, using:
  Accuracy = (TP + TN) / (TP + TN + FP + FN)
  Precision_class = TP_class / (TP_class + FP_class)
  Recall_class = TP_class / (TP_class + FN_class)
  F1 = 2 * (Precision * Recall) / (Precision + Recall)
- Confusion matrices sourced from `metrics.json`; images rendered via `presentation_viz/visualize_results.py` into `presentation_viz/confusion_matrices_grid.png`.

4.2 ANALYSIS OF RESULTS

Logistic Regression Strength on SMS
- TF-IDF n-gram coverage (1–2 grams, 5k features) efficiently captures key spam cues (e.g., “claim now”, “libre load”) without overfitting.
- Simple linear decision boundary generalizes well when feature space is sparse and balanced; small dataset size (≈6k samples) aligns with LR’s bias toward precision.
- Threshold tuning via `evaluate_models.py` found an optimal spam probability cutoff near 0.52, balancing 99.4 % spam precision with 90.1 % spam recall.

LSTM Underperformance on Limited Data
- Requires large, diverse sequence pairs to learn long-term dependencies. With ~4.8k training messages, the model overfits despite dropout (0.2–0.3) and early stopping.
- Heavy text normalization (stopword removal, stemming) reduced contextual cues, weakening embeddings and hurting recall.
- Padding to length 100 introduces noise for short SMS, leading to vanishing gradients; CPU-only training further limited hyperparameter sweeps.

XLM-RoBERTa Excellence on Bilingual Texts
- Pretrained on 100+ languages with subword tokenization, enabling robust handling of Taglish code-switching and borrowed slang.
- Contextual embeddings capture multi-word expressions and semantics (e.g., “mag-claim now”, “limited slots po”), boosting both ham precision (0.9917) and spam recall (0.9767).
- Transformer attention handles long-range dependencies and multilingual morphology without custom preprocessing, explaining highest F1 (0.967).

Error Case Highlights (From `metrics.json` confusion matrices & manual inspection)
- Logistic Regression false negatives: promotional messages with obfuscated vocabulary (“invst na w/ frnds”) lacking previously seen n-grams.
- LSTM false negatives: legitimate conversational spam (storytelling) where model fails to focus on call-to-action tokens after aggressive stopword stripping.
- XLM-RoBERTa false positives: ham messages containing financial/banking keywords (legitimate reminders) and bilingual honorifics, showing need for domain-specific fine-tuning.

4.3 DISCUSSION OF FINDINGS

Relation to Literature
- Confirms prior SMS studies (e.g., Almeida et al., 2013) reporting strong TF-IDF + LR baselines when datasets are small but feature-rich.
- Aligns with Bahdanau et al. insights that RNNs require ample labeled sequences to outperform bag-of-words; our LSTM results echo underperformance reported by Cruz et al. (2021) for Filipino SMS.
- Extends multilingual transformer findings (Conneau et al., 2020) to Taglish spam: subword modeling + cross-lingual pretraining deliver superior recall on code-mixed texts.

Support or Contradiction vs. Previous Work
- Supports the notion that classical models remain competitive when feature engineering captures domain cues.
- Contradicts earlier expectations that LSTMs automatically outperform classical models; highlights dataset size and preprocessing choices as limiting factors.
- Reinforces recent work showing transformers excel on bilingual tasks even without task-specific tokenizers, thanks to shared subword vocabularies.

Contribution to Bilingual NLP Research
- Provides a reproducible pipeline (dataset builder + three modeling paradigms + unified evaluator) tailored to Taglish SMS, filling a gap in publicly documented bilingual spam systems.
- Demonstrates empirically that XLM-RoBERTa can serve as a drop-in multilingual detector with minimal hyperparameter tuning, guiding future work on Filipino dialect expansion.
- Supplies artifacts (metrics, confusion matrices, visualization scripts) and code references that other researchers can reuse when benchmarking new bilingual spam defenses or ensembling models.
